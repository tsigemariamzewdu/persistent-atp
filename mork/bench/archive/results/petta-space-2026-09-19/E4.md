## What this run shows

- `empty-match`: median 176.15 → 203.94 µs from scale 0 to 1000 (1.16×).

This is one sweep on one machine. These observations do not establish an asymptotic complexity, an absence of interference, or a performance regression. No latency budget or pass/fail performance threshold was applied.

Each query/cycle has 3 discarded warm-ups and 30 measured samples in a fresh PeTTa process for each scale. Startup, graph loading, module imports, and sample printing are excluded. Timer/evaluation overhead remains.

## Reproduce

From the repository root:

```sh
.venv/bin/python -m mork.bench --experiment E4 --allow-petta-space \
  --output-dir /tmp/petta-e4 --json /tmp/petta-e4.json
```
