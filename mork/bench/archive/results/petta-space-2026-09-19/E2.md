## What this run shows

- `node`: median 4.68 → 4.41 µs from scale 50 to 1000 (0.94×).
- `incoming-edges`: median 4.26 → 5.92 µs from scale 50 to 1000 (1.39×).
- `outgoing-edges`: median 7.43 → 59.02 µs from scale 50 to 1000 (7.94×).

This is one sweep on one machine. These observations do not establish an asymptotic complexity, an absence of interference, or a performance regression. No latency budget or pass/fail performance threshold was applied.

Each query/cycle has 3 discarded warm-ups and 30 measured samples in a fresh PeTTa process for each scale. Startup, graph loading, module imports, and sample printing are excluded. Timer/evaluation overhead remains.

## Reproduce

From the repository root:

```sh
.venv/bin/python -m mork.bench --experiment E2 --allow-petta-space \
  --output-dir /tmp/petta-e2 --json /tmp/petta-e2.json
```

Evidence: [all raw result rows](results.json), [run output](run.log), and [run overview](README.md). Generated programs and per-case logs remain locally in `generated/` (excluded from Git because they contain machine-specific paths).
